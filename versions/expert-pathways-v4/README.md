# 小悠 · 浅蓝工作台前端源码

打包日期：2026-10-21。对应本次回滚后在 http://127.0.0.1:8771/#home 展示的版本。

## 本地运行

这是原生 HTML / CSS / JavaScript 项目，无需 npm 安装、构建或 API Key。

1. 解压 ZIP，进入 chengxiaoyou-demo 文件夹。
2. 电脑安装 Python 3 后，在该文件夹打开终端并运行：

```sh
python3 -m http.server 8771 --bind 127.0.0.1
```

Windows 可使用 `py -m http.server 8771 --bind 127.0.0.1`。

3. 浏览器访问 http://127.0.0.1:8771/#home 。
4. 结束预览时，在运行服务的终端按 Ctrl+C。

若端口已被其他服务使用，可把命令中的 8771 改为 8780，并访问相应地址。项目使用 ES modules，请通过 HTTP 服务打开，不能直接双击 index.html。

## 代码结构

- index.html：应用入口。
- src/app.js：布局、路由、项目、弹窗、事件与键盘交互。
- src/chat.js：原版首页、任务输入、对话与执行状态。
- src/viewer.js：成果预览、批注、局部修改、版本与导出。
- src/catalog.js：插件、技能、MCP、专家。
- src/workspace.js：定时任务、知识库和设置等页面。
- src/personal.js：小悠主动建议、关注事项、偏好确认与记忆。
- src/core.js：初始样例、状态、图标与公共工具。
- 根目录 CSS：页面样式与响应式布局。
- assets/：海豚形象和应用图标。

## 原型说明

这是可操作的前端 Demo，包含合成示例。尚未接入真实模型、飞书、携程业务系统、电脑控制或后台定时调度。普通任务使用预设成果；文件批注、编辑与部分导出会修改当前浏览器的本地数据。

对话、设置、知识库等修改保存在当前浏览器的 localStorage，存储键为 chengxiaoyou.replica.v1。源码包包含初始演示数据，不包含原浏览器里的临时会话和个人修改。首次在新地址或新浏览器打开，会显示初始样例。

本包保留当前实际加载的代码与图片，已排除撤回的首页风格文件、试验备份和验收截图。
