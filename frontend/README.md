# 小悠 · 前端交互页面

更新日期：2026-10-26。采用白色、浅灰和深色按钮的简洁 UI，团队空间用于集中管理插件、专家和知识库。先创建或进入空间，空间内只有「空间资源」「成员配置」两个主页面。创建者和管理员维护资源，成员查看和使用；任务与成果仍归个人。

## 直接打开 HTML（推荐）

在访达中双击 **`程小悠.html`**，用 Chrome、Edge 或 Safari 打开即可。样式、脚本和图片均已内嵌，不需要 Python、终端或本地服务。以后更新同一路径下的这个文件，在原浏览器标签页刷新即可。

单文件也包含站点发布页。站点链接使用当前 HTML 的 `#published/...` 路径，仍然读取当前浏览器保存的内容。请固定文件位置和文件名，以便继续使用同一份本地数据。原 `http://127.0.0.1:8771` 下的数据仍保存在原地址，浏览器不会自动将它迁移到本地文件地址。

维护源码后执行 `python3 build-standalone.py`，会更新同一个 `程小悠.html`。交付和日常预览只需这一个 HTML 文件。

## 多文件源码运行（可选）

这是原生 HTML / CSS / JavaScript 项目，无需 npm 安装、构建或 API Key。

**macOS 推荐方式：双击文件夹内的 `启动程小悠.command`。** 它会检测本机预览服务；未运行时自动启动，再用浏览器打开页面。启动成功后可以关闭终端窗口。电脑重启后再次双击即可。

预览地址是本机地址，并非在线托管链接。出现 `ERR_CONNECTION_REFUSED` 表示本机预览服务未运行，请重新打开启动入口。始终使用 `http://127.0.0.1:8771`，以继续读取同一浏览器中的现有数据。

也可以手动运行：

1. 解压 ZIP，进入 chengxiaoyou-demo 文件夹。
2. 安装 Python 3 后，在该文件夹打开终端并运行：

```sh
python3 -m http.server 8771 --bind 127.0.0.1
```

Windows 可使用 `py -m http.server 8771 --bind 127.0.0.1`。

3. 浏览器访问 <http://127.0.0.1:8771/#home>，或直接打开 <http://127.0.0.1:8771/#teams>。
4. 结束预览时，在运行服务的终端按 Ctrl+C。

若端口已被使用，可把 8771 改为 8780，并访问相应地址。项目使用 ES modules，须通过 HTTP 服务打开，不能直接双击 index.html。

## 团队空间使用流程

入口：侧栏「团队空间」，或 <http://127.0.0.1:8771/#teams>。

1. 在空间列表点击「创建团队空间」，填写名称和说明。创建者自动成为首位成员。
2. 进入「空间资源」，按「插件」「专家」「知识库」切换查看。创建者和管理员可以从小悠已有资源中添加，也可以新建空间知识库。
3. 编辑空间专家，在「关联插件」「关联知识库」中选择本空间已有的资源。创建者或管理员保存一次后，成员打开专家就会自动带上这些资源。
4. 进入「成员配置」，通过姓名、拼音或飞书邮箱搜索并选择成员、选择管理员或成员角色、调整已加入成员的角色、移除成员，或撤销待接受的邀请。
5. 成员从空间选择资源，用于自己的任务。对话、附件和成果不会成为空间共享内容。

| 角色 | 查看和使用资源 | 新增、编辑、移除资源 | 邀请和管理成员 |
| --- | --- | --- | --- |
| 创建者 | 可以 | 可以 | 可以；创建者不能被改为其他角色或移除 |
| 管理员 | 可以 | 可以 | 可以；不能修改自己的角色、移除自己或操作创建者 |
| 成员 | 可以 | 不可以 | 不可以；可以查看成员列表 |

权限限制同时在页面入口和数据操作中检查。移除成员后，该成员不能再进入空间或继续执行依赖空间资源的任务；已保存的个人历史内容保留。

### 空间资源

| 类型 | 如何维护 | 成员如何使用 |
| --- | --- | --- |
| 插件 | 从现有插件中添加；编辑空间内的名称和说明 | 添加到新任务，由小悠按需使用 |
| 专家 | 从现有专家中添加；编辑名称、说明和工作方法，关联本空间的插件与知识库 | 开始个人对话，自动带上已配置的插件和知识库 |
| 知识库 | 添加已有知识库副本，或新建并填写知识内容；可编辑说明和内容 | 查看资料，引用到自己的任务 |

添加后形成空间内的独立副本。修改或移除空间资源不会改动小悠中的原始资源，也不会影响另一个空间。同一来源在同一空间不能重复添加。个人知识库不会自动共享；需要创建者或管理员明确选择添加。

资源保存后即在空间内生效，没有套件、发布预览和二次发布流程。

空间专家只关联同一空间中的插件和知识库。成员无需手动重复添加；专家带入的知识引用可查看，不能在任务里单独移除。创建者或管理员可以清空关联，也可以重新选择。不能关联已停用资源，也不能通过一个向全员开放的专家间接分享仅少数成员可见的旧资源。

空间资源的名称最多 80 个字符、说明最多 500 个字符，添加已有资源和编辑空间副本使用同一限制。空间本身的名称和说明仍分别最多 50 和 300 个字符。搜索后新建知识库或添加资源会清空旧搜索条件，立即显示新增资源。

修改知识库、插件或专家后，新任务和未发送的草稿会使用最新配置；草稿里的个人输入、附件、额外引用、模型选择及手动选择的专家会保留。主动移除的工具或知识引用不会因刷新页面而恢复，只有重新点击使用该资源才会添加回来。示例问题在已有输入末尾追加，重复点击同一示例不会重复插入。

专家当前关联的资源失效时，未发送的旧草稿会保留输入并阻止发送；修复关联后可继续使用。已开始的任务保留使用时的资源快照，后续编辑不会覆盖其指令或引用正文。插件和知识库若仍被专家关联，必须先解除关联才能移除。旧任务引用的资源被停用、移除或不再向当前成员开放时，不能继续执行，已有对话和成果仍可查看。

### 个人任务与账号连接

- 选择专家、插件、知识库或任务示例，只准备个人草稿，不自动发送。已有未发送的输入会保留。
- 专家自动使用管理员配置的工作方法、插件和知识库。单独从空间选择插件或知识库时，它们作为普通任务的工具或引用，可在发送前移除，已输入内容、附件和模型选择保留。
- 如果专家关联的插件需要个人账号，在发送前只提示当前任务实际需要的连接；不会继承创建者或其他成员的授权。返回编辑保留输入和附件，确认演示连接后只发送一次。
- 连接确认期间，如果空间配置发生变化，确认操作会停止发送、保留草稿并要求重新核对；不会静默授权后来新增的插件。
- 连接状态在团队入口、插件页和任务工具选择中保持一致，其他成员的连接不会带入当前用户。旧任务按原快照所需的账号检查连接。
- 成果预览、批注、修改和下载沿用个人工作台。

「产品体验团队」展示当前用户作为创建者的页面；「数据分析团队」展示同一用户作为普通成员的页面。示例成员 A 在产品体验团队中是管理员。团队与成员均为演示数据。

## 站点使用流程

入口：侧栏「更多 → 站点」，或 <http://127.0.0.1:8771/#sites>。

1. 点击「在会话中试用」（空列表也可点击「创建第一个站点」），进入建站输入框。预填内容可以修改，点击发送才开始生成。
2. 小悠根据本次描述生成网页草稿。先预览页面，再发布；生成完成不会自动发布。
3. 发布后，站点进入列表，并获得固定的本地地址。可直接打开，也可复制链接；复制失败时会显示可手动选择的完整地址。
4. 在站点上点击「更多 → 编辑」，进入绑定该站点的会话草稿，自动带上站点地址和修改指令。已有未发送的输入会保留。
5. 发送修改要求后生成新版草稿。确认发布更新前，原站点继续展示上一版；确认后更新同一站点、保留原链接。
6. 站点列表支持搜索、刷新、查看使用说明及删除。删除后原地址不可打开，可以在当前列表提示中撤销本次删除；历史对话仍然保留。

这里的发布保存到当前浏览器，不连接公网托管。链接在同一浏览器与相同本地服务地址下可打开；其他电脑和浏览器无法读取这份本地发布数据。网页内容由本地规则生成，未调用真实模型。旧版站点资料会保留为未发布草稿，不会自动变成已发布页面。

## 原型边界

这是可操作的前端 Demo，包含合成示例。尚未接入真实模型、飞书、携程业务系统、电脑控制、组织目录或后台定时调度。普通任务使用预设成果；文件批注、编辑和部分导出修改当前浏览器的本地数据。

邀请操作只在本地保存「待加入」记录，不会发送真实邮件或通知，也不会自动把被邀请人变成已加入成员。搜索使用本地示例成员，尚未连接飞书企业通讯录。没有真实多人同步、邀请接受服务或跨客户端权限服务。账号连接同样只记录演示状态，不访问真实账号。

对话、空间资源、成员角色、邀请、设置和知识库等修改保存在当前浏览器的 localStorage，键为 `chengxiaoyou.replica.v1`。源码包含初始样例，不包含原浏览器里的临时会话和个人修改。在新地址或新浏览器打开时，会使用新的本地状态。

本版不包含共享对话、协作台、实时编辑同步、团队执行队列、团队模型额度和共享产物区。项目范围以用户本轮明确的「空间资源 + 成员配置」为准。

## 旧数据保留

- 旧版已发布的套件资源迁移为空间资源；未发布套件和草稿归档到 `teamSpace.legacyBundleArchive`，不自动公开。
- 旧资源如只面向指定成员，迁移后保留原使用范围。相同来源但配置不同的资源分别保留，避免把仅指定成员可见的配置扩散给其他成员。
- 旧团队任务继续保留当时的资源快照、输入和成果。未发送草稿会映射到新资源；出现映射冲突时保留两份草稿，不覆盖输入或附件。
- 旧专家的隐含插件配置，只能迁移为同空间内已有且可用范围覆盖该专家的插件关联。不会自动把空间外的插件或个人知识库加入空间，已明确清空的关联不会恢复。
- 更早的个人项目配置、资料和草稿保存在 `legacyProjectArchive`，不会自动成为团队资源。可从「查看原型范围 → 导出旧项目资料」导出。
- 旧项目记忆在记忆设置中归档保留，不自动带入新的个人任务。旧 `#projects` / `#project/...` 地址转到团队空间。
