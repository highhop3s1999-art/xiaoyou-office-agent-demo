# 小悠办公 Agent Demo

可点击、可输入、可连续操作的桌面办公 Agent 产品原型。当前版本：`20261026-15.0`，更新日期：2026-10-26。

以用户提供的前端为基础，展示“小悠主 Agent + 企业专家 + 执行现场 + 持续任务”的办公入口。下表优先列出本轮新增及改造的产品能力。

## 新增与重点改造的能力

| 能力 | 当前产品设计与可体验内容 | 主要入口 |
| --- | --- | --- |
| 专家成为持续工作入口 | 从专家市场或分享链接保存专家，固定到左侧；同一专家支持新建独立对话，消息、草稿、引用资料、任务分别保存；支持历史搜索、切换与重命名 | 我的专家、专家页顶部 |
| 专家下展开对话 | 新建后自动在左侧对应专家下展开并选中；子对话可直接切换；专家和最近工作各露出 3 条，专家下先露出 3 条对话，可查看全部 | 左侧我的专家 |
| 三种专家协作方式 | 小悠按任务组织临时子 Agent；在会话中 @ 已保存的企业专家；固定企业专家后直接与其持续对话。临时子 Agent 与可复用企业专家分别呈现 | 主会话、@ 专家、固定专家 |
| 编排层产品化 | 展示目标、角色、步骤、依赖与交付物；支持调整步骤顺序、角色与依赖，增补或删除可选步骤；修改后更新计划版本及相关检查 | 对话右侧的计划面板 |
| 对话与执行环境融合 | 中央保留正常对话，右侧按需查看计划、执行、成果、确认与回放；可补充要求、暂停、继续；连接失败时保留已完成成果并从失败步骤恢复 | 主会话、右侧工作面板 |
| 子 Agent 独立过程 | 点击子 Agent 打开它自己的工作标签，查看收到的任务、过程记录、工具动作、上游依赖、重试和交付版本；可返回主会话继续讨论 | 对话中的子 Agent、右侧子智能体 |
| 独立验收与 Lead 自核 | 按目标覆盖、指标口径、来源和操作边界显示逐项检查及证据；验收失败退回修正，交付前再由 Lead 自核 | 右侧确认与验收 |
| 操作级人工确认 | 确认具体动作、对象、内容版本及批准范围；拒绝后停止相关交付，内容或计划变化使旧批准失效；重复点击不会重复产生回执 | 任务内确认面板 |
| 任务中心 | 将原定时任务入口改造成任务控制中心；支持看板与列表、执行状态、进度、暂停与恢复、专家分工入口；点击任务回到所属对话查看成果，中心不重复铺陈产出 | 任务中心 |
| 事件任务与自动任务 | 定时、常驻关注、飞书消息、文档变化、邮件及业务事件的规则配置；支持范围与关键词、发送人、被 @、排除自身及机器人、冷却、去重、运行记录；新事件可关联已有运行 | 任务中心的事件任务、自动任务 |
| 飞书上下文引导 | 搜索飞书聊天、相关文档、会议总结三个快捷入口；点击向输入框追加可编辑提示词，由用户补充后发送，帮助发现跨应用上下文能力 | 首页与会话输入区上方 |
| Skill 主动推荐与沉淀 | 入口推荐工作方法，对话中按目标建议 Skill，用户明确采用后绑定当前任务；重复完成同类工作后可保存方法，形成私人、停用、待审核的 Skill 草稿 | 工作方法、会话建议、完成后的保存提示 |
| 本机 Agent 统一入口 | 我的专家的 + 菜单接入 Claude Code、Codex；统一放入我的专家，提供独立工作区、草稿和演示连接管理 | 我的专家 + → 接入本机 Agent |
| 个人主动入口与记忆演进 | 工作概览、主动性 L0–L3 约定、关注成果变化、长期记忆入口及个人/项目范围；处理事项时返回原任务现场，敏感操作继续按次人审 | 主动协助 |
| 首页与导航精简 | 首页只保留交办工作、继续工作两个模块；合并重复的小悠/工作首页入口，保留项目、专家、插件和任务中心的职责 | 工作首页、左侧导航 |

以上为当前 Demo 的产品交互与本地状态能力。动态组队、推荐、查询、检查及任务执行由预设场景和本地规则模拟，不代表已接入实际模型与企业服务。

## 沿用并增强的基础能力

- 文本交办、附件与引用、输入草稿、项目归属、历史搜索及任务管理。
- 文档、表格、网页和演示文稿的成果查看器，以及多标签、翻页、缩放等交互。
- 元素批注、表格编辑、局部修改、版本差异、撤销与冲突保护；新增成果版本与验收、操作确认的关联。
- 插件 / Skill / MCP 管理、专家配置、知识库、个人与项目记忆、项目分组等基础组件。
- 真实支持的本地导出格式：HTML、CSV、Markdown；不将其标成原生 PPTX、XLSX 或 DOCX。

## 当前边界与后续接入

- 本机 Agent 连接为演示状态，不会启动 Claude Code / Codex 或向它们提交真实任务。
- 飞书快捷入口只填写提示词，未执行飞书 CLI；事件订阅、后台定时器、业务系统写回、消息发送、授权及发布均为本地模拟。
- 企业 MCP 网关、凭据托管、身份权限继承、DLP、租户隔离、集中审计与成本控制台不应计入已完成的服务能力。
- 小队模板入口已按产品调整移除；当前保留的是确认过的工作方法沉淀为 Skill 草稿。
- 浏览器 localStorage 保存演示进度。GitHub 中包含源码与初始合成样例，不包含本机浏览器里的个人会话与临时修改。

## 本地运行

原生 HTML / CSS / JavaScript，无需安装 npm 依赖、构建或配置 API Key。

在仓库根目录运行：

```sh
python3 -m http.server 4314 --bind 127.0.0.1
```

访问 `http://127.0.0.1:4314/frontend/#home`。端口被占用时可换一个端口。请通过 HTTP 打开，不能直接双击 HTML；项目使用 ES modules。

## 建议体验顺序

1. 首页交办一项经营复盘，查看对话与右侧计划。
2. 打开子 Agent 的工作过程，再回到主会话。
3. 修改计划并执行，体验暂停、失败恢复、验收和具体操作确认。
4. 到我的专家保存专家，尝试 @ 专家、固定专家及新建独立对话。
5. 在左侧专家下切换对话，验证草稿与任务隔离。
6. 到任务中心查看看板、事件规则、示例触发和原任务会话。
7. 体验飞书上下文提示词、Skill 推荐和本机 Agent 的模拟接入。

## 代码与版本

- `frontend/`：当前 Demo，入口为 `frontend/index.html`。
- `frontend/src/`：对话、专家、编排、任务、事件、Skill、成果与本地状态模块。
- `tests/`：产品状态与交互规则回归检查。
- `screenshots/`：当前版本及任务中心的关键页面。
- `versions/`：历史界面快照，用于原型中的版本对照；不代表当前上线范围。
- `verification-v15.json`：最近一轮浏览器与回归检查记录。
